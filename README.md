# 図形のへんしん実験室

小学校の図形学習で、図形を動かしながら性質を見つけるための軽量Webアプリです。

初期版は小学3年生の「円」を対象にします。設計・実装方針は [引き継ぎ書](docs/figure-learning-lab-handoff.md) を参照してください。

## 開発

依存関係はありません。`index.html` をブラウザで開くか、静的ファイルサーバーで確認してください。

## 現在の段階

- Phase 1: 画面遷移と共通UI
- Phase 2: 円の中心・半径・試行点の操作、手書き、戻す
- Phase 3: 図と手書きをPNGとして保存
- 次段階: 児童端末での実機検証と、試行結果によるUI調整
