# 3年算数「円と球」活用アイデア

## ねらい

このアプリは、正しい答えを選ばせるドリルではなく、児童が図形を動かし、比べ、言葉にするための「実験装置」として使う。円と球の学習では、次の3点を中心にする。

- 円周上の点は、中心からの長さが等しい。
- 直径は中心を通り、半径の2つ分の長さである。
- 球は、どの向きから見ても円に見え、中心から表面までの長さが等しい。

## 実装した案：球の「どこから見ても円」実験

### 問い

> ボールをちがう向きから見ると、外がわの形はどう見えるかな。

### 画面でできること

1. 模様と陰影が付いた球を指で左右・上下に回す。
2. 向きを変えるたびに、見えた影をスタンプする。
3. スタンプごとに色を変えて並べ、すべて同じ円になるか確かめる。
4. 球の模様は回転し、光の当たる位置と床の影は動かないことから、球そのものを回していると捉える。

### この方法をすすめる理由

- 実物のボールでは見えない中心や半径を、画面なら同時に示せる。
- 何度回しても条件を保てるので、「見た目がたまたま同じ」ではなく、向きを変えても同じことを試せる。
- 円の学習で使った「中心から同じ長さ」という見方を、そのまま球へつなげられる。

### 授業での流れ（10〜15分）

1. **予想する**：「横から見ると、形は変わる？」を近くの人と話す。
2. **試す**：球をいろいろな向きに回し、3方向の輪郭を集める。
3. **重ねる**：輪郭を重ねて、同じ円になることを確かめる。
4. **説明する**：「球は、どこから見ても……」の続きを一文で書く。
5. **実物で確かめる**：ボールや地球儀を回し、画面での発見と結び付ける。

> 画面だけで完結させず、最後に実物へ戻す。端末は見えない中心を可視化するために使い、手触りや重さは実物で扱う。

## ほかに活用できる方法

### 1. 半径ものさしで「円になる場所」を探す

現在の「同じ長さのところに点を打つ」活動を、教室内の探索へ広げる。

- **画面**：中心と半径を決め、点をたくさん打って円を作る。
- **実物**：ひもとチョークで、校庭に同じ仕組みの大きな円を描く。
- **問い**：「画面の棒と、校庭のひもは、どんな同じはたらきをしている？」
- **期待する言葉**：「中心からの長さを同じにしている。」

デジタルと実物を往復することで、円を単なる丸い見た目ではなく、作られ方の条件で捉えられる。

### 2. 直径を探す「いちばん長い線」実験

円の端から端まで線を引き、線を平行移動させながら長さを比べる。

- 中心を通るときだけ線を強調する。
- 数値は最初から出さず、長さの違いを見た後に表示する。
- 「いちばん長い線は、どこを通る？」と問う。
- 最後に、半径2本を直径へ重ねる。

直径を用語から教えるのではなく、比較の結果として中心を通る線に着目させる。

### 3. 円と球の「切った形」を予想する

球を切る位置を上下に動かし、切り口の円が大きくなったり小さくなったりする様子を比べる。

- **予想**：切る前に「円／だ円／四角」から予想し、理由を話す。
- **操作**：切る面を中心へ近づける。
- **発見**：中心を通る切り口が最も大きく、その直径は球の直径と同じになる。

発展的な活動なので、全員の必須課題にはせず、理解が進んだ児童の追加実験や授業終盤の提示に使う。

### 4. 「ころがる・ころがらない」を向きで比べる

球、円柱、箱を坂に置き、置く向きを変えて動きを予想する。

- 球は向きを変えても転がる。
- 円柱は置く向きによって転がり方が変わる。
- 画面では軌跡を残し、まっすぐ進むか、向きが変わるかを比べる。

形の名称当てにせず、「なぜその動きになるか」を表面の形と結び付けて説明させる。実際の運動には摩擦なども影響するため、実物実験とシミュレーションの結果が違う場合も話題にする。

### 5. 身の回りの「円／球」を仕分ける

マンホール、皿、時計、ボール、ビー玉などの写真を、次の3列に分ける。

| 円が見えるもの | 球の形のもの | どちらとも言い切れないもの |
|---|---|---|
| 時計、皿のふち | ボール、ビー玉 | 筒、厚みのある皿 |

「丸いもの」をすべて円と呼ぶ誤解を防ぐため、平面の形と立体を区別する。写真だけでは奥行きが分かりにくいものは「どちらとも言い切れない」に置けるようにし、答えより根拠を重視する。

### 6. 円を使った模様づくりから性質を説明する

同じ半径の円を、中心だけ動かして重ねる。花模様や波模様を作った後、「同じ長さになっているところ」を色や言葉で示す。

- 自由制作だけで終えず、中心と交点を線で結ぶ。
- できた正三角形やひし形は、後の図形学習への橋渡しにする。
- 作品画像に一文の説明を添えて共有する。

## 45分授業での組み合わせ例

| 時間 | 活動 | 端末・実物の役割 |
|---:|---|---|
| 5分 | ボールをどこから見ても同じ形か予想する | 実物を提示する |
| 10分 | 球を回し、3方向の輪郭を集める | 端末で繰り返し試す |
| 8分 | 輪郭を重ね、中心から表面への線を比べる | 見えない中心を可視化する |
| 10分 | 実物のボールと円い紙を比べる | 平面と立体を触って区別する |
| 7分 | ペアで発見を説明する | 相手の説明と比べる |
| 5分 | 一文でまとめる | 画像またはノートに残す |

## 実装する場合の優先順位

1. **実装済み：球を回す／影を色違いで集める**：円と球を直接つなぐ中心課題。
2. **中心と半径を表示する**：円で得た見方を球へ転用する。
3. **直径の比較**：円・球の両方で使える共通課題。
4. **切り口、転がり、仕分け、模様**：発展課題として段階的に追加する。

各課題の操作は「うごかす」「くらべる」「もどす」の最大3つに絞る。回転角や半径などの数値を常時表示するより、まず形の変化と不変な条件に注目させ、数値は確かめたいときだけ表示する。

## 見取りの観点

自動採点ではなく、操作と説明から次を見取る。

- 「丸いから」だけでなく、「中心から同じ長さ」と説明できるか。
- 円（平面）と球（立体）を言葉や例で区別できるか。
- 球を向きを変えて見ても輪郭が円になることを説明できるか。
- 予想と違った結果を、操作し直して確かめようとしているか。

保存する成果物は、最終画面の画像と短い一文で十分とする。点数化よりも、「どの操作を根拠に説明したか」を交流する材料として使う。
